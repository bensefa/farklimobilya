# Farklı Mobilya

**Mobilya sektörü için modern, responsive ve dijital vitrin odaklı kurumsal web projesi**

Farklı Mobilya için marka kimliğine uygun, ürün ve hizmetlerin güçlü biçimde sunulabildiği modern bir web deneyimi üzerinde çalışıldı.

> Bu repository bir **proje vitrini / portföy sayfasıdır**. Canlı sistemin kaynak kodları, erişim bilgileri ve hassas yapılandırmaları güvenlik nedeniyle yayımlanmamaktadır.

## Proje kapsamı

- Mobilya sektörüne özel kurumsal web tasarımı
- Modern ve responsive kullanıcı arayüzü
- Masaüstü ve mobil uyumluluk
- Ürün ve hizmet odaklı içerik sunumu
- Marka kimliğine uygun görsel yapı
- Kullanılabilirlik odaklı arayüz düzenlemeleri
- SEO dostu sayfa ve içerik mimarisi
- Performans odaklı web geliştirme
- İletişim ve müşteri erişimi odaklı yapı

## Teknolojiler

**Frontend:** HTML5, CSS3, JavaScript  
**Backend:** PHP  
**Web:** Responsive Web Design  
**Optimizasyon:** SEO, Performance, Mobile UX

## Portföy notu

Bu repository kaynak kod dağıtımı amacıyla değil, gerçekleştirilen web tasarım ve geliştirme çalışmalarını profesyonel portföyde göstermek amacıyla oluşturulmuştur.

Canlı sisteme ait veritabanı bilgileri, kullanıcı verileri, şifreler, API anahtarları, sunucu yapılandırmaları ve diğer hassas dosyalar yayımlanmaz.
